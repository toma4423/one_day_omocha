# 🎁 今日のおもちゃ箱 (One Day Omocha)

Streamlit を使用した、日常生活やゲームで使えるミニツール・ミニゲーム集です。
ブラウザさえあれば、PC でもスマホでも、すぐに遊んだり記録したりできます。

## 🚀 特徴
- **直感的なビジュアル編集**: 背景画像の上に画像を重ね、ドラッグ＆ドロップで位置やサイズを調整可能（Palmu予定表）。
- **マルチデバイス・タッチ最適化**: スマートフォンでも操作しやすい大きなボタンと、タッチ操作に最適化されたエディタ。
- **強力なデータ永続化 (LocalStorage)**: ブラウザを閉じたりリロードしたりしても、アップロードした画像や設定値が自動的に復元されます。
- **日本時間 (JST) 対応**: 履歴の記録やファイル名はすべて日本時間に基づいています。
- **プライバシー配慮**: データは利用者のブラウザ内にのみ保存され、サーバーには送信されません。

## 📦 収録されているおもちゃ
### 📊 クリエイター・配信支援系
1. **Palmu週間予定表**: ランクメーターに基づいた配信スケジュールの策定と、動的な行追加による柔軟な予定管理。
2. **Palmu月間予定表**: 最大4期先までのカレンダー自動生成。SKIPに応じた期間の自動延長・抑制ロジック搭載。
3. **ビジュアルエディタ**: Fabric.js を活用した、ブラウザ上で完結する高度な画像合成ツール。

### 🎲 ゲーム・エンタメ系
1. **チンチロリン**: 本格的な役判定とアニメーション。
2. **スロットメーカー**: 自分専用のスロットを作成・実行。
3. **ルーレット**: カスタマイズ可能な物理挙動ルーレット。
4. **すごろく・マインスイーパー・黒ひげ**: 定番のゲームツール群。

### 🔢 サポート・ツール系
1. **カウントサポート**: 複数の項目を倍率付きで同時カウント。
2. **並列カウンター**: 複数のカウンターを並べて管理。

## 🛠 開発者向け情報

### 技術スタック
- **Python 3.12+**
- **Streamlit**: Web UI フレームワーク
- **Fabric.js**: キャンバス操作・画像編集ロジック
- **Pillow**: サーバーサイド画像合成
- **uv**: 高速な Python パッケージ・プロジェクト管理
- **pytest**: 自動テスト

### セットアップと実行
```bash
# リポジトリのクローン
git clone https://github.com/toma4423/one_day_omocha.git
cd one_day_omocha

# 実行
uv run streamlit run app.py
```
