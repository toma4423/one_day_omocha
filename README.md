# 🎁 今日のおもちゃ箱 (One Day Omocha)

Streamlit を使用した、日常生活やゲームで使えるミニツール・ミニゲーム集です。
ブラウザさえあれば、PC でもスマホでも、すぐに遊んだり記録したりできます。

## 🚀 特徴
- **マルチデバイス対応**: スマートフォンでも操作しやすい大きなボタンとレイアウト。
- **自動保存機能 (LocalStorage)**: ブラウザを閉じたりリロードしたりしても、自分のデータが保持されます。
- **日本時間 (JST) 対応**: 履歴の記録やファイル名はすべて日本時間に基づいています。
- **セーブ＆ロード**: 盤面の状態を JSON ファイルとして保存・復元できます（ビンゴ、カウントサポート）。
- **プライバシー配慮**: データは利用者のブラウザ内にのみ保存され、サーバーには送信されません。

## 📦 収録されているおもちゃ
### 🎲 ゲーム・エンタメ系
1. **サイコロ**: 最大100個のダイスを一度に振れます。出目履歴の保存に対応。
2. **双六メーカー**: 自由にマス目を作れるすごろく。自動コマ移動とループ機能付き。
3. **黒ひげ危機一発**: ハラハラドキドキの定番ゲーム。スロット番号表示で遊びやすく改善。
4. **マインスイーパー**: クラシックな地雷撤去ゲーム。
5. **チンチロリン**: 本格的な役判定とアニメーション。役の履歴保存が可能。

### 🔢 サポート・ツール系
1. **カウントサポート**: 複数の項目（X, Y, Z）に倍率をかけて計算できるカウンタ。
2. **カウントサポートビンゴ**: 最大 15×15 のマス目で複数の項目を同時カウント。JSONでの保存に対応。

### セットアップと実行
このプロジェクトは `uv` を使用して管理されています。

```bash
# リポジトリのクローン
git clone https://github.com/toma4423/one_day_omocha.git
cd one_day_omocha

# 依存関係のインストールと実行
uv run streamlit run app.py
```

### テストの実行
```bash
uv run pytest
```

### プロジェクト構成 (Project Structure)

本プロジェクトは、Streamlitを使用したUI（表示層）と、Pythonによるコアロジック（計算層）を明確に分離する設計方針をとっています。これにより、新しい「おもちゃ」の追加やテストが容易になります。

- `app.py`: メイン（ホーム）画面
- `pages/`: 各おもちゃの個別ページ (Streamlit UI)
- `src/utils/`: 共通ユーティリティ・コアロジック (計算・判定)
- `tests/`: 自動テストコード (pytest)
- `history/`: 修正・拡充の記録
- `pyproject.toml`: 依存関係管理 (uv)

## 🛠 新しい「おもちゃ」の追加方法 (How to Add a New Toy)

新しい機能を追加する際は、以下のステップに従うことで堅牢な実装が可能です。

### 1. ロジックの設計 (`src/utils/`)
計算や状態判定などのコアロジックを、Streamlit（UI）に依存しない純粋なPython関数として実装します。
- `src/utils/new_toy.py` を作成。
- テストしやすいよう、入出力が明確な関数を定義します。

### 2. テストの作成 (`tests/`)
作成したロジックに対するテストを記述します。
- `tests/test_new_toy.py` を作成。
- 正常系、異常系、境界値（例：サイズ0や最大値）を網羅します。
- `uv run pytest` でテストがパスすることを確認します。

### 3. UIの実装 (`pages/`)
Streamlitを使用してUIを構築し、作成したロジックを呼び出します。
- `pages/X_🎨_新しいおもちゃ.py` を作成。
- ユーザー入力（`st.number_input`等）を受け取り、ロジック関数に渡します。
- 必要に応じて `src/utils/storage.py` を使用して状態を永続化します。
