# 🎁 今日のおもちゃ箱 (One Day Omocha)

Streamlit を使用した、日常生活やゲームで使えるミニツール・ミニゲーム集です。
ブラウザさえあれば、PC でもスマホでも、すぐに遊んだり記録したりできます。

## 🚀 特徴
- **直感的なビジュアル編集**: 背景画像の上に画像を重ね、ドラッグ＆ドロップで位置やサイズを調整可能（Palmu予定表）。
- **モバイル最適化**: スマートフォンで撮影した画像の向きを自動補正（EXIF対応）し、タッチ操作に最適化されたUIを提供。
- **強力なデータ永続化 (LocalStorage)**: ブラウザを閉じたりリロードしたりしても、アップロードした画像や設定値が自動的に復元されます。
- **日本時間 (JST) 対応**: 履歴の記録やファイル名はすべて日本時間に基づいています。
- **次世代を見据えた設計 (API-First)**: 全てのコアロジックを Pydantic モデルで構造化し、UI とロジックを完全に分離。将来の FastAPI 移行や Rust (WASM) 導入に対応。

## 📦 収録されているおもちゃ
### 📊 クリエイター・配信支援系
1. **Palmu週間/月間予定表**: ランクメーターに基づいた配信スケジュールの策定と、動的な予定管理。
2. **画像リサイズ**: 9:16や1:1など、SNSに最適なアスペクト比での切り抜き・リサイズ。iPhone/Androidの画像向きも自動補正。
3. **ビジュアルエディタ**: Fabric.js を活用した、ブラウザ上で完結する高度な画像合成・配置ツール。

### 🎲 ゲーム・エンタメ系
1. **チンチロリン**: 本格的な役判定とアニメーション。
2. **スロットメーカー**: 自分専用のスロットを作成・実行。確率設定も自由自在。
3. **ルーレット**: カスタマイズ可能な物理挙動ルーレット。
4. **神経衰弱**: 1人プレイまたは2人対戦が可能なトランプゲーム。
5. **すごろく・マインスイーパー・黒ひげ**: 定番のゲームツール群。

### 🔢 サポート・ツール系
1. **カウントサポート**: 複数の項目を倍率付きで同時カウント。
2. **カウントサポートビンゴ**: 目標達成をビンゴ形式で楽しく管理。
3. **並列カウンター**: 複数のカウンターを並べて管理・統計。

## 🛠 開発者向け情報

### 技術スタック
- **Python 3.12+**
- **Streamlit**: Web UI フレームワーク
- **Pydantic**: コアロジックのデータ構造化・バリデーション
- **Fabric.js**: キャンバス操作・ビジュアル編集
- **Pillow**: 高品質な画像処理・リサイズ
- **uv**: 高速な Python パッケージ・プロジェクト管理
- **pytest**: 堅牢な自動テスト環境

### セットアップと実行
```bash
# リポジトリのクローン
git clone https://github.com/toma4423/one_day_omocha.git
cd one_day_omocha

# 実行
uv run streamlit run app.py
```
