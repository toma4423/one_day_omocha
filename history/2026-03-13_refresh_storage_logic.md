# 2026-03-13 永続化ロジックの刷新とデータ消失対策

## 変更内容
スマートフォンのブラウザ等で発生していた、読み込み完了前のデフォルト値によるデータ上書き（データ消失）問題を解決するため、全ページの永続化ロジックを刷新しました。

### 1. 堅牢な初期化フローの導入
- `wait_for_storage_load` 関数を導入し、ブラウザの LocalStorage からデータが正しく読み込まれるまでページのレンダリングを待機するようにしました。
- これにより、通信ラグによるデフォルト値での意図しない上書きを防止しました。

### 2. 明示的な保存方式への移行
- 従来の「入力のたびに自動保存」する方式から、ユーザーが「💾 ブラウザに保存」ボタンを押した時のみ保存される方式へ変更しました。
- これにより、誤操作によるデータの破壊を防ぎ、状態の確定をユーザーがコントロールできるようになりました。

### 3. データ管理 UI の統一
- `render_storage_controls` 関数を導入し、以下の機能を全ページで統一された UI で提供するようにしました。
    - **ブラウザに保存**: LocalStorage への永続化。
    - **JSON保存**: 現在の設定をファイルとしてエクスポート（バックアップ）。
    - **JSON読込**: バックアップファイルから設定を復元。

## 影響範囲
- ユーザーは設定変更後、明示的に保存ボタンを押す必要があります（保存せずにページを離れると変更が破棄されます）。
- 初回読み込み時に「データを読み込み中...」という表示が出る場合があります。
