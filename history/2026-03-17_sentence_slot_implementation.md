# 2026-03-17 新機能：文章スロット「誰が・何を・どうした」の実装

## 概要
新しいおもちゃとして、3つの項目を組み合わせて面白い文章を作成できる「文章スロット」を追加しました。各項目の自由な追加・削除、独立した回転演出、および堅牢な保存機能を備えています。

## 変更内容
### 1. 新規ページの追加 (`pages/18_🎰_文章スロット.py`)
- 「誰が」「何を」「どうした」の3つのリールを持つスロット UI。
- **一括回転** および **個別回転** に対応。
- ページ下部に項目編集エリア（テキスト追加・❌ボタン削除）を配置。
- レスポンシブレイアウトにより、PC/スマホ両方で快適に操作可能。

### 2. アニメーションの実装 (`src/assets/sentence_slot/`)
- 文字列の長さに柔軟に対応する JavaScript ベースのテキストスクロール演出。
- スピン中のブラー効果による視覚的な楽しさを提供。

### 3. データロジックと保存機能 (`src/utils/sentence_slot.py`)
- Pydantic モデルによる厳密なデータ構造。
- `random.choice` を使用した「完全均等」な抽選ロジック。
- `SafeStorage` と Dirty フラグによる LocalStorage 同期。
- JSON ファイルによる設定の書き出し・読み込み機能。

### 4. テストの追加 (`tests/test_sentence_slot.py`)
- 出現確率が均等であることを統計的に検証（10,000回試行）。
- データ移行およびデフォルト設定の初期化を検証。

## 品質管理
- **自動テスト**: 全 103 項目（新規 4 項目含む）のテストがパス。
- **静的解析**: Ruff および Mypy のチェックをクリア。
