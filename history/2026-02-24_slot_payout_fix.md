# 修正記録: 2026-02-24 (バグ修正: スロット表示)

## 30. スロット役一覧の表示エラー修正
ID管理への移行に伴い、スロットページで役のパターンを表示する際に `TypeError` が発生していた問題を修正しました。

### 原因
- 以前は図柄パターンが文字列のリスト（例: `["🍒", "🍒", "🍒"]`）だったため `" ".join()` が可能だったが、IDベース移行後は数値のリスト（例: `[1, 1, 1]`）になり、数値に対して `join` を試みたためクラッシュした。

### 修正内容
- **ユーティリティ追加**: `src/utils/slot.py` に `resolve_pattern_to_chars` を実装。数値IDを対応する図柄文字へ変換し、UI表示に適した形式にする処理を共通化。
- **UI修正**: スロットページの役一覧表示部分で上記ユーティリティを使用するように変更。

### テストの強化
- `tests/test_slot.py` に ID -> 文字変換のテストケースを追加。
- 予期せぬデータ型による UI クラッシュを防止するためのチェック体制を整備。
