# 2026-03-01 Streamlit コンポーネントの互換性修正 (ルーレット)

## 概要
本番環境（Streamlit Cloud）で `st.components.v1.html` に `key` 引数を渡すと `TypeError` が発生する問題を修正しました。

## 修正内容
- **互換性対応**: `st.components.v1.html` から `key` パラメータを削除しました。一部の Streamlit 環境や Python 3.13 向けの内部実装で、この引数が `unexpected keyword argument` となる現象を確認したためです。
- **再描画トリガーの変更**: 
    - `key` の代わりに、HTML 文字列内に `<!-- refresh_key: __TRIGGER__ -->` という動的なコメントを埋め込むようにしました。
    - コンテンツ自体が変化（トリガー数値が更新）することで、Streamlit に「新しいコンテンツ」であると認識させ、アニメーションの再実行を促します。
- **型安全性の強化**: JSON 文字列化や置換処理において、より厳格な型チェックと例外処理を追加しました。
