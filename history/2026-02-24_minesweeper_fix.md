# 修正記録: 2026-02-24

## 1. 確認された問題
- **マインスイーパーのエラー**: サイドバーでボードの高さ（または幅）を変更した際、以前のボードサイズを参照し続けることでインデックス外参照（IndexError）が発生し、アプリがクラッシュする。

## 2. 修正内容
### マインスイーパーの修正
- **サイズ変更検知**: サイドバーでの入力値（幅・高さ・爆弾数）を現在のボードの状態と比較し、変更があった場合に自動でゲームステータスを `ready` に戻すロジックを追加。
- **ロジックの抽出**: 描画とロジックを分離するため、`src/utils/minesweeper.py` を新規作成し、ボード生成、マスのオープン（再帰処理）、クリア判定の関数を抽出。
- **ページのリファクタリング**: `pages/4_💣_マインスイーパー.py` を更新し、ユーティリティ関数を使用するように変更。

### テストの拡充
- **新規テスト**: `tests/test_minesweeper.py` を作成し、コアロジックのユニットテストを実装。
- **既存テストの強化**: `tests/test_dice.py`（チンチロの全役判定）、`tests/test_storage.py`（LocalStorage操作のモックテスト）を強化。
- **テスト実行**: `uv run pytest` ですべてのテスト（21項目）がパスすることを確認。

## 3. 残っている作業・今後の課題
- **他のページのリファクタリング**: 同様にUI内にロジックが埋もれているページ（双六、ビンゴ等）のロジック抽出とテスト追加。
- **LocalStorageの堅牢化**: 現在は `st.session_state` に依存している部分があるため、より純粋なストレージ操作への抽象化の検討。
