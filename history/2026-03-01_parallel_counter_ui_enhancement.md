# 2026-03-01 並列カウンターの UI/UX 刷新

## 概要
並列カウンターの見た目を、JavaScript と CSS を活用したモダンで「ガジェット風」なデザインに大幅に刷新しました。

## 変更内容
- **カスタムデザインの導入**:
    - `src/assets/counter/style.css` を作成し、カード型のレイアウト、シャドウ、角丸を定義。
    - 各カウンターを独立したカードとして描画し、視覚的なまとまりを向上。
- **動的アニメーションの追加**:
    - 数値が更新された際、対象のカウンターにのみ `pulse-effect` クラスを付与。
    - CSS `@keyframes` を用いて、数値が強調されるアニメーションを実装。
- **ボタンスタイルの最適化**:
    - 増減ボタンの役割に応じた色分け（増：ブルー、減：グレー）とサイズ調整。
    - ホバーエフェクト（拡大、色変化）を追加し、操作感を向上。
- **レスポンシブ対応**:
    - CSS Grid を使用し、デバイスの画面幅に合わせて 1〜3 列に自動的にレイアウトされるように調整。

## 確認事項
- [x] 各操作ボタンが正常に機能し、LocalStorage に保存される。
- [x] 数値更新時にパルスアニメーションが発生する。
- [x] モバイル表示でもレイアウトが崩れない。
- [x] すべてのユニットテストがパスしている。
