# 2026-03-01 ルーレット機能の強化

## 概要
ルーレットのアニメーションが動作しない問題を修正し、物理演算ベースの減速と音響効果を大幅に強化しました。

## 変更内容
- **アセットの分離**: 描画ロジック（`src/assets/roulette/wheel.js`）とスタイル（`src/assets/roulette/style.css`）を外部ファイル化。
- **物理演算アニメーション**:
    - Python 側で当選項目を決定後、JS 側で「その項目で止まる初速」を計算して減速を開始する仕組みに刷新。
    - イージング関数を適用し、自然な回転・停止を実現。
- **音響効果 (Audio Context API)**:
    - 針がスライスの境界線を跨ぐ瞬間を JS でリアルタイム検知。
    - カチカチ音を実際の回転角度に同期して再生。
- **UI/UX 改善**: 
    - `roulette_spin_trigger` を使用して Python のボタンから JS への実行指示を確実に伝達。
    - `render_donation_box` のリンクを実際の PayPay リンク（`qr.paypay.ne.jp`）に更新。

## 確認事項
- [x] Streamlit の「回す」ボタンでアニメーションが開始される。
- [x] 当選項目で正確に停止し、Python の履歴と一致する。
- [x] 回転中に「カチカチ音」が適切に鳴る（設定で ON/OFF 可能）。
- [x] すべてのテストがパスし、品質チェックも合格。
